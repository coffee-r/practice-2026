## 概要

Go言語で作るハイスコアランキングWebAPIの習作です。

## ルール

* ハイスコアを整数で登録できる
* ハイスコア登録に併せてプレイヤーを識別するnameを登録できる
* nameはuniqueである
* ハイスコア値は0以上の整数
* nameは10文字以内
* 単一グループのランキングである
* xxxイベントランキングやyyyイベントランキングのようにランキングを複数持つことはできない
* プレイヤー登録できない、プレイヤーデータは正規化せずに、ハイスコアデータに持たせる
* 同じプレイヤーがスコアを登録しようとした場合はハイスコアを優先して更新・ないしは更新しない
* ハイスコア値を大きい順に並べたランキングを表示できる
* ハイスコア値が同じ場合は登録日時が古い方を優先してランク付けする
* nameを指定して、そのnameのランキングを取得できる
* ランキングを指定して、そのnameを取得できる
* ランキングはページネーションが可能
* チート対策は考慮外
* APIの認証は練習としてJWTを検証するendpointを1つ用意
* Redisは使わない


## API CALL

### スコアの登録・更新

```sh
$ curl -X POST -H "Content-Type: application/json" -d '{"name":"太郎", "score":30}' http://localhost:8080/scores -w "HTTP %{response_code}\n"
```
